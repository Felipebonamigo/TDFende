Arquivos de balanceamento do TDFende
====================================

Estes são os valores de FÁBRICA, exportados do código. Servem como ponto de partida.

COMO USAR
  1. Copie estes arquivos para a pasta de dados do jogo. O caminho aparece quando você
     clica em "Exportar balanceamento" no menu inicial.
  2. Edite os números.
  3. Dê Play. O jogo carrega no boot e avisa no Console.

REGRAS DO FORMATO
  - Uma linha por unidade/torre.
  - Campo ausente usa o valor de FÁBRICA daquele bicho/torre, então dá para escrever só o que muda
    (ex.: "name=Lobo;cost=40" muda só o custo do Lobo).
  - A CHAVE é key= (minúscula, sem acento: lobo, aguia, canhao). É ela que liga a linha ao bicho/torre;
    name= é só o texto exibido e o jogo ignora o que estiver ali (o log avisa se diferir).
    Arquivo antigo, só com name=, ainda funciona (casa pelo nome, com um aviso para exportar de novo).
    Chave que o jogo não conhece ou repetida recusa o arquivo inteiro, com a linha no aviso.
  - Bicho ou torre que o arquivo não cita continua no jogo com os valores de fábrica, e a ordem
    das linhas não importa: o jogo mantém a sua.
  - Linha começando com # é comentário.
  - DECIMAL COM PONTO: 2.75, nunca 2,75.
  - Salve em UTF-8 (é como estes arquivos já estão) para os acentos não quebrarem.

SE ERRAR
  Arquivo inválido nunca derrota o jogo: aparece um aviso no Console dizendo a linha do
  problema, e a partida roda com os valores de fábrica. Apagar os arquivos volta ao padrão.

O QUE NÃO DÁ PARA MUDAR AQUI
  A quantidade de tipos, a ordem e os nomes: vêm do jogo. Apagar uma linha não remove o
  bicho (ele volta com os valores de fábrica). O arquivo só é lido no boot — nunca no meio
  de uma partida.
